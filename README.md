# 📊 Sales Performance & Target Achievement Dashboard

An interactive **Microsoft Excel dashboard** designed to analyze sales performance, target achievement, and executive-level sales trends.

## 📌 Project Overview

The **Sales Performance & Target Achievement Dashboard** converts raw sales data into meaningful business insights through interactive visualizations and performance metrics.

The dashboard focuses on evaluating sales executives across different regions, comparing their actual sales against predefined targets, and identifying performance gaps.

## 🎯 Project Objectives

* Analyze sales performance across multiple days
* Track total sales generated by each sales executive
* Measure target achievement percentage
* Identify high-performing and under-performing executives
* Compare sales performance across regions
* Visualize sales trends and performance metrics
* Support data-driven performance evaluation

## 🛠️ Tools & Technologies

* **Microsoft Excel**
* Excel Formulas
* Data Cleaning & Preparation
* Data Analysis
* Pivot Tables / Charts
* Interactive Dashboard Design
* Data Visualization

## 📂 Dataset

The dataset contains sales information for multiple sales executives across different regions.

### Key Fields

| Field              | Description                              |
| ------------------ | ---------------------------------------- |
| Emp Code           | Unique employee identifier               |
| Sales Executive    | Name of the sales executive              |
| Region             | Assigned region                          |
| Day 1 – Day 5      | Daily sales performance                  |
| Total Sales        | Total sales generated                    |
| Target             | Assigned sales target                    |
| Target Hit %       | Percentage of target achieved            |
| Away From Target % | Percentage remaining to reach the target |

## 📊 Dashboard Features

### Executive Performance

Provides a clear view of individual sales executive performance and helps identify top and low performers.

### Target Achievement

Tracks the percentage of target achieved by each executive and highlights performance against the assigned target.

### Regional Analysis

Allows comparison of sales performance across different regions.

### Daily Sales Analysis

Analyzes sales generated across five working days to identify changes and trends in performance.

### KPI-Based Visualization

Important sales metrics are presented through visual KPIs and charts for quick interpretation.

## 📈 Key Metrics

The dashboard calculates and presents:

* **Total Sales**
* **Sales Target**
* **Target Hit %**
* **Away From Target %**
* **Executive-wise Performance**
* **Regional Performance**
* **Daily Sales Trends**
